<!-- 5. ARCHITECTURE                                                           -->
<!-- ========================================================================= -->
### Architecture

Requests flow from the client through a FastAPI / Next.js Gateway into the **AI Agent Hub**, which orchestrates a Planner, Coder, and Research agent against a shared memory and RAG layer backed by a vector database. PostgreSQL, Redis, and Kafka handle state, caching, and event streaming; every request is measured through evaluation and monitoring before the whole system ships on Docker + Kubernetes.
